# OROFILA — Static Gem & Jewelry Website

A multi-page, responsive luxury gemstone & jewelry website for **Orofila**.

## Pages
- `index.html` — Home
- `collection.html` — Collection / inquiry cards
- `gemstones.html` — Gemstone-focused information
- `gallery.html` — Photo + reel gallery with frame-based video previews
- `about.html` — Brand story and buying flow
- `contact.html` — WhatsApp / Instagram / phone contact

## Tech
- HTML5
- CSS3
- Tailwind CSS via CDN (no Node.js, no build step)
- Vanilla JavaScript

## Run
Open `index.html` in a browser, or upload the whole folder to any static hosting provider.
